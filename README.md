# Розвідувальний аналіз даних (EDA) продажів кав'ярні

У проекті я провів очищення та розвідувального аналізу (EDA) сирих даних продажів кав'ярні за рік за допомогою Python (pandas, numpy, matplotlib, seaborn). За мету я собі поставив провести підготовку даних, логічне відновлення пропущених значень, а також дослідити продажі, оцінити поведінку клієнтів (середній чек, популярні товари) та перевірити якість логування інформації.


## Структура файлів
* cafe_sales_eda.ipynb - Jupyter Notebook з повним кодом, процесом очищення та покроковим розбором датасету.
* [data](csv_files/dirty_data) - дані про продажі (джерело: [Cafe Sales - Dirty Data for Cleaning Training](https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training)).
* [clean_data.csv](csv_files/clean_data.csv) - фінальний очищений датасет, підготовлений для подальшого використання.

## Ключові результати аналізу

В процесі підготовки даних та EDA було виявлено кілька важливих бізнес-патернів, а також серйозні проблеми зі збором інформації:

1. Середній чек становить 8.93, а медіанний 8.0. Клієнти купують в середньому по 3 товари (середня кількість 3.02, медіана 3.0). Перевірка статистичними методами (через міжквартильний розмах) показала, що аномалій та нетипових викидів у транзакціях немає.
2. Повністю відсутня різниця у продажах по місяцам. Місячний прибуток стабільно тримається на рівні від 6633 до 7350. Розподіл замовлень по днях тижня також максимально рівномірний (близько 13-14% щодня).
3. Найбільше наприбутковіші товари: приносять салати, смузі та сендвічі.
4. Також варто додатково провести аналіз причин великої кількості пустих значень у стовпчиках локації та методу відплати, оскільки це корисні для аналізу дані.
